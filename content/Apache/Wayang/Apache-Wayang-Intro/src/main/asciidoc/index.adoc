== What is Apache Kafka?
[%step]
1.	*Distributed Event Streaming Platform:* Apache Kafka enables the collection, storage, and processing of high-throughput, real-time data streams.
2.	*Pub-Sub Messaging System:* Kafka allows producers to publish messages to topics and consumers to subscribe, ensuring reliable data delivery.
3.	*Real-Time Data Pipelines:* Kafka supports seamless integration between diverse systems, enabling data movement and processing in real-time.
4.	*Core for Modern Architectures:* Widely used for event-driven applications, microservices, and analytics in industries like finance, retail, and tech.

== What is Apache Wayang?

[%step]
1. *Cross-Platform Data Processing:* Apache Wayang (formerly Rheem) enables unified data processing across multiple platforms like Apache Spark, Flink, and TensorFlow.
2.	*Platform-Agnostic Abstraction:* Provides a high-level API to decouple application logic from specific execution engines, increasing flexibility.
3.	*Cost-Optimized Workflows:* Dynamically optimizes execution plans to balance performance and resource utilization across heterogeneous environments.
4.	*Multi-Engine Interoperability:* Seamlessly integrates diverse processing engines, leveraging their unique strengths within a single pipeline.

== Block 3: Praktische Einblicke und zukünftige Perspektiven

=== Aktueller Ansatz

image::./image-2024-11-12-21-35-02-288.png[]

=== Aktueller Ansatz
[%step]
- Raw-Data flows into a Kafka cluster.
- The cluster is now in the same security context as the raw data.
- Multiple custom connectors are needed.
- A Streaming-Application runs the data processing steps on top of Kafka.
- The overall logic must be implemented using Streaming apps, using the data in our cluster.
- Results are piped forward into a target cluster, out of the owners control.

=== Kooperative Datennutzung mit Confluent Cloud

image::./image-2024-11-12-19-38-59-442.png[]

=== Neuer Ansatz
[%step]
- Wayang Multi-Context can process the data in place in multiple systems, and only brings the non-sensitive data into the cluster.
- A Wayang Plan Executor processes the non-sensitive data and optionally also other remote data which is still sensitive in its original context.
- The cluster never sees any sensitive data, and all logic can be expressed in the same language, as part of a Wayang-Plan.
- Execution can be done on existing fully managed components, such as Kafka Connect and Apache Flink, both provided by Confluent cloud.
